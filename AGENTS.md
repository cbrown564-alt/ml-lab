# ML Lab

Build interactive machine-learning exhibits that let a learner see, run, alter, and explain a model. Prove one complete exhibit before spreading a pattern across the catalogue.

`PRODUCT.md` owns product behavior and `DESIGN.md` owns the interface system. The numbered files in `docs/` own decisions, architecture, model and content rules, evaluation, and the roadmap. Update the existing owner; do not add a parallel plan.

Keep model behavior and explanations technically accurate. Mark generated media and synthetic examples as provisional. Verify affected interactions and visuals in the browser. Run `npm run validate`, `npm run typecheck`, and focused tests while iterating; run the strict rubric and build checks before a broad completion claim.
