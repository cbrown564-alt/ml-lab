# ML Lab media sprint workspace

This directory holds provisional generation masters, prompts, contact sheets, and review records. Nothing here is a shipping asset. An approved asset moves to `public/` only after it is tested in its exhibit and its status changes to `approved-for-integration` in `manifest.json`.

## Status vocabulary

- `briefed`: grounded in stable product or exhibit copy; ready to generate.
- `generated`: a master exists but has not been reviewed in a real screen.
- `shortlisted`: worth testing in a real screen.
- `provisional-reference`: selected to guide this sprint, not yet a permanent project standard.
- `approved-for-integration`: checked for teaching fit, visual fit, responsive cropping, and provenance.
- `rejected`: retained only when it documents an important failure mode.
- `blocked`: missing a stable script, approved direction, or generation capability.

## Rules

1. Generated media carries atmosphere, metaphor, or recurring character continuity. Model geometry, plots, equations, architecture diagrams, and exact mechanisms remain code or SVG.
2. Every job names the existing exhibit or reusable system need that grounds it.
3. Preserve the original master and prompt. Derivatives never replace the master.
4. Generated media remains visibly provisional until reviewed in the actual ML Lab surface.
5. Silent loops must have a useful poster frame and must not carry teaching content unavailable elsewhere.
